#MERN Stack Netflix Clone – Project Description

I developed a Netflix Clone using the MERN stack (MongoDB, Express.js, React.js, Node.js) that replicates the core functionality and design of the Netflix platform. The application allows users to sign up, log in, browse movies/TV shows, and stream video content, providing a seamless and engaging user experience.

🔹 Key Features

User Authentication – Secure login & registration using JWT and bcrypt for password hashing.

Dynamic UI – Responsive and modern Netflix-style UI built with React.js and styled components.

Movie & TV Show Listings – Integrated with TMDB (The Movie Database) API to fetch and display trending, popular, and category-based movies.

Search & Filter – Users can search movies/shows by title and explore categories.

Video Streaming – Implemented embedded video players for trailers and movies.

Watchlist – Users can add/remove movies from their personalized watchlist stored in MongoDB.

Role-Based Access – Admin dashboard to manage users and content.

Persistent Sessions – Authentication tokens stored securely, ensuring smooth navigation.

🔹 Tech Stack

Frontend: React.js, Redux (for state management), Axios, Styled Components

Backend: Node.js, Express.js (REST API for authentication and content handling)

Database: MongoDB (Mongoose ORM for schema and queries)

Authentication: JWT (JSON Web Tokens), bcrypt

API Integration: TMDB API for movie/TV metadata

Deployment: Hosted on platforms like Render/Heroku (backend) and Vercel/Netlify (frontend)

🔹 Highlights

Built a scalable full-stack architecture similar to production-grade streaming platforms.

Optimized API calls and caching to improve performance.

Designed a Netflix-like UI/UX with hover effects, sliders, and carousels.

Implemented secure authentication and state persistence.
